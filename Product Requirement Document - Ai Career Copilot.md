# Product Requirement Document (PRD)

## Product Name

AI Career Copilot – Intelligent Student Career Guidance Platform

## 1. Purpose

The purpose of this product is to provide an AI-powered platform that helps students identify suitable career domains, evaluate resumes, understand skill gaps, and receive personalized preparation roadmaps. The system aims to reduce confusion and improve placement readiness.

## 2. Problem Statement

Students struggle to:

* Choose appropriate career domains
* Understand required skills
* Assess resume readiness
* Create structured preparation plans
* Benchmark their progress

## 3. Goals & Objectives

* Provide career recommendations based on interests and skills
* Offer automated resume analysis
* Generate personalized preparation roadmaps
* Benchmark student readiness
* Adapt learning plans using feedback

## 4. Target Users

* Undergraduate and postgraduate students
* Final-year students preparing for placements
* Career counselors and mentors

## 5. Key Features

### 5.1 Career Recommendation Engine (S1)

Maps student interests and background to relevant career domains.

### 5.2 Preparation Roadmap Generator (S2)

Creates step-by-step learning timelines and checklists.

### 5.3 Resume Analyzer (S3)

Evaluates resume formatting, keywords, and ATS compatibility.

### 5.4 Company Explorer (S4)

Provides domain-specific company listings.

### 5.5 Readiness Benchmarking (S5)

Assesses preparation level using quizzes and scoring.

### 5.6 Skill Prioritization (M1)

Ranks skills based on importance and gaps.

### 5.7 Adaptive Learning Planner (M2)

Adjusts roadmap based on performance.

### 5.8 Project Recommendation Engine (M3)

Suggests portfolio projects from job descriptions.

### 5.9 Market Trend Analyzer (H1)

Tracks trending skills from job data.

### 5.10 Closed-loop Feedback System (H2)

Refines strategy based on mock interviews and project feedback.

## 6. User Flow

1. User registers and creates a profile
2. Inputs interests and skills
3. Receives career recommendations
4. Uploads resume for analysis
5. Takes readiness assessment
6. Receives adaptive roadmap
7. Tracks progress via dashboard

## 7. Success Metrics

* User engagement rate
* Resume improvement scores
* Completion of learning milestones
* User satisfaction feedback

## 8. Constraints

* Must use free and open-source tools
* Should run on low-cost infrastructure
* Must be scalable and modular

## 9. Timeline (Hackathon Scope)

* Phase 1: Core features prototype
* Phase 2: AI modules integration
* Phase 3: Testing and demo preparation
