# Tech Stack Requirement Document (TRD)

## 1. Overview

This document defines the open-source technologies used to build the AI Career Copilot platform.

## 2. Frontend Technologies

* React.js for UI development
* Tailwind CSS for styling
* Vite for fast builds
* Chart.js for visualizations

## 3. Backend Technologies

* Python with FastAPI framework
* RESTful API architecture
* Uvicorn server

## 4. AI & NLP Libraries

* Hugging Face Transformers
* spaCy NLP toolkit
* Sentence Transformers
* scikit-learn for ML utilities

## 5. Database

* SQLite for lightweight storage
* Optional MongoDB Community Edition

## 6. Data Processing & Scraping

* BeautifulSoup for web scraping
* Requests library for HTTP handling
* Pandas for data processing

## 7. Authentication & Security

* JWT-based authentication
* HTTPS encryption

## 8. Development Tools

* Git & GitHub for version control
* VS Code as IDE
* Docker (optional for deployment)

## 9. Deployment Options

* Vercel (frontend)
* Render or Railway (backend free tier)
* GitHub Pages (static hosting)

## 10. System Requirements

* Python 3.10+
* Node.js 18+
* Minimum 8GB RAM for AI processing

## 11. Scalability Strategy

* Containerized deployment
* Modular microservices architecture
* API-first design
